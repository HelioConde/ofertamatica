## Verificações

- A lista está coberta por `scripts/validate-coverage-redirects.mjs` integrado a `npm run check:build`.
- `scripts/verify-live-seo.mjs` testa casos importantes com HTTP reais após o deploy FTP.
- Apenas URLs canônicas entram no sitemap; alias redirecionado não pode ter canônica própria.
- Os 301 devem manter a intenção de busca. Não redirecionar campanhas sem correspondência apenas para forçar redução de erros.
- Após publicação, reenviar sitemap e usar **Validar correção** no Search Console. A queda dos avisos históricos depende de novo rastreamento do Google e não é imediata.
