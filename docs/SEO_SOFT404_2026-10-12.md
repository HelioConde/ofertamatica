## Verificações

- A lista está coberta por `scripts/validate-coverage-redirects.mjs` integrado a `npm run check:build`.
- `scripts/verify-live-seo.mjs` testa casos importantes com HTTP reais após o deploy FTP.
- Apenas URLs canônicas entram no sitemap; alias redirecionado não pode ter canônica própria.
- Os 301 devem manter a intenção de busca. Não redirecionar campanhas sem correspondência apenas para forçar redução de erros.
- Após publicação, reenviar sitemap e usar **Validar correção** no Search Console. A queda dos avisos históricos depende de novo rastreamento do Google e não é imediata.

## Revisão de 22/10/2026 — URLs adicionais no Search Console

Outras duas exportações disponibilizadas em 22/10/2026 listaram **9 URLs não encontradas (404)** e **3 URLs alternativas com canônica adequada**. Os totais representam classificações históricas do Google, não novos erros produzidos por esta alteração.

- **301 com destino equivalente:** `/placas-promocionais` → `/gerador-de-cartaz-de-promocao/`; `/cartaz-de-oferta` → `/criador-de-cartaz-de-oferta/`; `/placas-para-farmacia` → `/cartazes-para-farmacia/`; `/placa-2x1` → `/formatos/`.
- **404 legítimo (sem página equivalente publicada):** `/ia-para-varejo`, `/ia-para-supermercado` e `/placa-sra3`. Uma futura funcionalidade SRA3, caso implementada, deve ser publicada antes de mudar seu status.
- **410 legítimo:** `/registro?plan=gratis` e `/registro?plan=plus`. O fluxo atual é gratuito sem cadastro e não mantém essas páginas de conta.
- **Canônicas alternativas:** `http://ofertamatica.com.br/`, `http://ofertamatica.com.br/login` e `/registro?plan=premium` constam no relatório. Essa categoria não implica necessariamente defeito a corrigir.

A visão geral de indexação também mostra **13 URLs descobertas e 13 rastreadas que não foram indexadas**. Nenhuma das três exportações anexadas traz o inventário individual dessas 26 URLs; não é possível decidir a correção específica delas somente pela contagem. O próximo diagnóstico exige exportar separadamente as tabelas das categorias **Detectada, mas não indexada no momento** e **Rastreada, mas não indexada no momento** e comparar cada URL com as rotas canônicas atuais.

Para facilitar a descoberta orgânica, a central `/guias-para-varejo/` agora contém link HTML rastreável para o editor livre. O teste de build confere o link e o smoke test pós-FTP cobre sitemap, robots, rotas 301, 404 e 410 adicionais.

**Atenção:** as validações de implantação confirmam somente HTTP e HTML publicado, não indexação no Google. O Search Console precisa rastrear novamente as URLs para atualizar as categorias. Não pedir indexação de URL que deveria continuar em 404/410.
